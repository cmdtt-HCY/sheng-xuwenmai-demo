# 「声叙文脉」有声叙事赋能地方文旅

新媒介下在地文化传播服务项目 Demo 静态网页。

- 项目定位：高校传媒专业（播音主持 / 广播电视编导）团队，以有声叙事赋能地方文旅在地文化传播
- 服务产品：在地口述档案采集制作、故事化有声导览内容全案、新媒体内容定制、线下文化体验活动策划
- 生产流程：田野调研 → 访谈采集 → 脚本审核（文史 / 非遗顾问）→ 配音制作 → 后期包装 → 交付成品

本页面为比赛 / 演示用 Demo，页面内图片与音频均为 AI 生成的示例素材，财务数据为策划书测算值，仅供参考。

## 页面结构

- 首页：项目概览、双轮驱动模式、服务产品、生产流程、案例、商业模式（营收 / 融资）、团队、未来规划
- 导览 Demo：手机形态有声导览播放器（示例音频、版本切换、字幕同步）
- 项目档案：概述、竞品对比、财务与融资、风险与对策

## 本地运行

直接打开 `index.html` 即可（音频 / 图片使用相对路径，需保持 assets 目录结构）。
